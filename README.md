# 🏥 Hospital Patient Analysis using Python

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a hospital patient dataset using **Python**. The goal is to analyze patient demographics, department visits, waiting times, billing information, and other healthcare-related insights through statistical analysis and visualizations.

## 🎯 Objectives

* Analyze patient demographics such as age and gender.
* Identify the most and least visited hospital departments.
* Study patient distribution across different cities.
* Analyze hospital waiting times.
* Examine consultation fees, medicine costs, test costs, and total bills.
* Visualize important trends using charts for better understanding.

## 📂 Dataset

The dataset contains hospital appointment and patient-related information, including:

* Patient ID
* Age
* Gender
* City
* Department
* Waiting Time
* Consultation Fee
* Medicine Cost
* Test Cost
* Total Bill
* Other appointment details

## 📊 Analysis Performed

### Data Cleaning

* Checked duplicate records
* Identified missing values
* Removed missing records

* Total number of patients
* Gender distribution

### Department Analysis

* Number of patients in each department

* Least visited department

### City Analysis

* Least common city

### Waiting Time Analysis

* Average waiting time
* Minimum waiting time
* Maximum waiting time

### Billing Analysis

* Average consultation fee
* Average medicine cost
* Average test cost
* Average total bill

## 📈 Visualizations

The project includes the following charts:

* Bar Chart – Patient Gender Distribution

## 🚀 How to Run

1. Clone the repository.
2. Install the required libraries.

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open the Jupyter Notebook.

```bash
jupyter notebook hospital_patient_analysis.ipynb
```

4. Update the dataset path if required.

5. Run all cells to generate the analysis and visualizations.
